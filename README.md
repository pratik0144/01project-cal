# Online Overtime Calculator

A modern, fast, and comprehensive overtime pay calculator built with [Astro](https://astro.build) and [Tailwind CSS v4](https://tailwindcss.com).

## 🚀 Features

- **50-State Overtime Rules**: Accurately calculates overtime according to federal (FLSA) and state-specific labor laws (California daily & 7th day double-time, Alaska, Colorado, Nevada, etc.).
- **Multiple Rate Types**: Hourly, daily, and weekly calculations.
- **Detailed Breakdown**: Regular hours, overtime hours, double-time hours, and gross pay.
- **Interactive UI**: Responsive, accessible, and clean design.

## 📂 Repository Structure

- **`galactic-gravity/`**: Astro web application source code.
- **`reference/`**: Research reports and comprehensive 50-state overtime rules dataset.
- **`DESIGN.md`**: Design system specifications, tokens, and UI layout documentation.

## 🛠️ Getting Started

### Prerequisites

- Node.js (>= 22.12.0)
- npm or pnpm

### Running Locally

```bash
cd galactic-gravity
npm install
npm run dev
```

The app will be available at `http://localhost:4321`.

### Building for Production

```bash
cd galactic-gravity
npm run build
```
